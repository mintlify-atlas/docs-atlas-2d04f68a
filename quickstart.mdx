---
title: "Quickstart"
description: "Get ColorMe running and pick your first color in under 5 minutes"
---

This guide walks you through cloning, building, and loading ColorMe in Firefox so you can pick your first color immediately. Firefox is used here because it is the only browser with full theme support via the `browser.theme.update()` API.

<Steps>
  <Step title="Clone the repository and install dependencies">
    ```bash
    git clone https://github.com/ehcaw/colorme.git
    cd colorme
    ```

    <CodeGroup>

    ```bash npm
    npm install
    ```

    ```bash yarn
    yarn install
    ```

    </CodeGroup>
  </Step>

  <Step title="Build for Firefox">
    <CodeGroup>

    ```bash npm
    npm run build:firefox
    ```

    ```bash yarn
    yarn build:firefox
    ```

    </CodeGroup>

    Webpack compiles the extension into the `dev/firefox/` directory. You should see output files including `manifest.json`, `popup/index.html`, and `background/background.js`.
  </Step>

  <Step title="Load the extension in Firefox">
    1. In the Firefox address bar, navigate to `about:debugging`.
    2. Click **This Firefox** in the left sidebar.
    3. Click **Load Temporary Add-on...**
    4. Navigate to `colorme/dev/firefox` and select `manifest.json`.

    The ColorMe icon appears in the Firefox toolbar.
  </Step>

  <Step title="Open the ColorMe popup">
    Click the ColorMe icon in the Firefox toolbar. The popup opens showing the color wheel, the current hex value, and the day/night toggle.

    On first load, the popup reads the saved `mode` from extension storage and defaults to `day` (frame color `#ffffff`) if no prior state is found.
  </Step>

  <Step title="Pick a color">
    Drag anywhere on the color wheel to select a hue, or drag toward the center to adjust saturation and lightness. The hex value displayed below the wheel updates in real time.

    As soon as you release the drag, `browser.theme.update()` fires and the Firefox frame (toolbar, tab bar, and sidebar) immediately changes to the selected color — no page reload needed.
  </Step>

  <Step title="Toggle day / night mode">
    Click the toggle switch at the bottom of the popup to switch between **light** and **dark** modes. Each mode stores its own independent frame color:

    - **Day (light)**: defaults to `#ffffff`
    - **Night (dark)**: defaults to `#000000`

    The active mode is persisted in extension storage and restored the next time the popup opens.
  </Step>

  <Step title="Save a color swatch">
    With the color you want displayed in the hex field, click the **+** button next to the toggle. ColorMe appends the hex value to your saved colors list in extension storage. Saved swatches appear in the `ColorTable` grid inside the popup and can be reapplied at any time.
  </Step>
</Steps>

<Tip>
  Check the Guides section for deeper features including live reload during development (`yarn dev:firefox`), building for Chrome and Opera, and packaging a production-ready zip for the browser extension store.
</Tip>
