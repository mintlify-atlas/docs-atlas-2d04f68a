## What is ColorMe?

ColorMe is a browser extension that lets you take full control of your browser's visual theme. Using an interactive color wheel, you can choose any hex color and apply it to your browser frame instantly — no restart needed.

The extension stores your preferences using the browser's built-in sync storage, so your color choices persist across sessions and devices.

## How it works

ColorMe is built with React and TypeScript, bundled with Webpack for each target browser. The popup UI hosts a color wheel that sends theme updates directly to the browser via the WebExtensions `browser.theme.update()` API.

<Steps>
  <Step title="Install the extension">
    Build for your browser and load the unpacked extension from the `dev/` directory.
  </Step>
  <Step title="Open the popup">
    Click the ColorMe icon in your browser toolbar to open the color picker popup.
  </Step>
  <Step title="Pick a color">
    Drag the handle on the color wheel to select any hue and saturation. The browser theme updates instantly.
  </Step>
  <Step title="Toggle day/night">
    Use the toggle switch to switch between your light (day) and dark (night) color themes.
  </Step>
  <Step title="Save your favorites">
    Click the **+** button to save the current color as a swatch for quick access later.
  </Step>
</Steps>
